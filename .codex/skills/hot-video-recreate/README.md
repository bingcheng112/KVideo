## 🎯 解决什么问题

**hot-video-recreate** 解决 AI 视频制作中两个最头疼的问题：

### 1. 爆款视频复刻

任何平台上的爆款视频，本质上都是一组被市场验证过的信号集合——分镜节奏、运镜方式、转场密度、情绪曲线。直接照搬，会被判同质化。完全不管，又浪费了现成的爆款公式。

hot-video-recreate 提取参考视频的**结构 DNA**（镜头构成、节奏分布、运动语法、转场逻辑），再迁移到你的产品或品牌上——保留原作的爆款骨架，但输出的视频只属于你。

> **底层逻辑**：视频平台的爆款视频，里面的元素大概率已被市场验证。直接复刻会触发同质化降权；忽略又等于放弃已验证信号。hot-video-recreate 做的事，是把爆款的骨架保留、领域的外皮替换——跨品类迁移，不撞同质化红线。

**适合谁**：带货卖家、新媒体达人、品牌营销——任何需要把产品做成有效视频、又不想每次都从零开始的人。

### 2. 智能模型路由

不是每一段画面都需要最强模型。Seedance、可灵、万相、VEO、Sora——每个模型都有自己的甜点区。有的擅长真人表情，有的擅长产品特写，有的擅长文字叠加。把所有任务都扔给旗舰模型，等于用大炮打蚊子。

hot-video-recreate 的**路由器**了解每个模型的能力边界，把每一段素材分配给「刚好能胜任、且成本最低」的模型。现阶段已支持 Seedance 不同版本之间的同质量降本路由。后续将陆续接入可灵、万相、VEO 等模型。

> **底层逻辑**：每个模型都有自己独特的价值曲线。将所有任务交给最厉害的模型，当然可行，但成本极高且严重浪费算力。路由模型做的事，是把不同任务分配给最适合它的模型，尽可能榨干每一个模型的算力，在保持质量一致的前提下实现极致降本。

**当前路由能力**：Seedance 各版本（fast / pro 等）——相同视觉质量，不同成本。  
**即将接入**：可灵、万相、VEO、Sora 等视频生成模型。

**成本**：采用官方 API，最低可做到 ¥0.4/秒，质量不打折。

## ⚖️ 与「文生视频」工具有什么不同

| 文生视频工具 | hot-video-recreate |
|---|---|
| 你用文字描述想要什么 | 你给一条参考视频——它会理解它**怎么**做到的 |
| 一个模型包揽一切 | 根据任务特征智能路由到不同模型 |
| 你凭感觉猜什么是好视频 | 爆款 DNA 是**提取出来的，不是拍脑袋想的** |
| 不管什么任务，成本都一样 | 按需匹配——只为每段画面付该付的钱 |
| 绑定单一模型 | 多模型冗余——永远不锁死在单个 API 上 |

一句话：文生视频工具让你当导演，hot-video-recreate 给你一条校准过的产线。

## 🧬 复刻流程

```text
参考视频 + 产品图
        ↓
   [规范化] — 格式化输入，探测时长
        ↓
   [人脸检测] — 有真人照片则走彩铅合规流程
        ↓
   [拆解] — 提取爆款 DNA：分镜构成、节奏、运镜、转场
        ↓
   [迁移] — 将 DNA 迁移到目标产品 / 领域
        ↓
   [编译] — 生成逐段生成提示词
        ↓
   [路由] — 每段匹配最优模型（成本 x 质量）
        ↓
   [生成] — 通过 Seedance / 可灵 / 万相 / VEO 渲染
        ↓
   outputs/<run_id>/segments/*.mp4
```

## 🧠 为什么这能成立

**对于爆款复刻**：平台上的爆款视频，其结构特征（镜头时长分布、运动强度曲线、转场密度）是统计信号，不是创作偶发事件。将这些信号迁移到新领域，会保留已验证的有效部分，而领域转变本身天然避免了同质化。

**对于模型路由**：视频生成模型的能力剖面并不重叠。擅长真人表情的模型，用来做纯产品特写+文字的镜头就是浪费；擅长快速出片的模型，适合 B-roll 但不适合英雄镜头。路由器学习这些能力边界并据此分配任务——这跟 CDN 比源站更便宜的逻辑一脉相承。
